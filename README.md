# Carola Menudeo

Reconstrucción desde cero con Next.js, React, TypeScript y Tailwind CSS.

## Conexión existente

Se conserva el proyecto Supabase `hnivrzcjxjofgzgopmbv`. Configura las variables de `.env.example` en `.env.local` y en el hosting. No se incluyen llaves privilegiadas. No se modificaron tablas ni datos.

## Ejecutar

```bash
npm install
npm run dev
```

La nueva aplicación es una base inicial, no un sistema de ventas funcional. Configura las variables antes de conectar módulos a la base.
